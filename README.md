# rosana2.borzanti.com — versão alternativa (estática)

Exportação estática do site alternativo da Dra. Rosana Borzan, gerada a partir de `D:\Sites\rosana-alt`
(projeto TanStack Start) com:

    cd D:\Sites\rosana-alt\app
    STATIC_EXPORT=1 VITE_SITE_URL=https://rosana2.borzanti.com bunx --bun vite build

e cópia de `app/dist/client` para cá (sem a pasta `presets`). Versão de avaliação: `noindex` + `robots.txt` bloqueando tudo.
